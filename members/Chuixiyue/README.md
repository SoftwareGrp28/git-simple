## 第一次 Git 实验总结
1. `git add` 的作用是:
将工作区中修改好的文件添加到暂存区，为后续 commit 做准备，不会生成版本快照。

2. `git commit` 的作用是:
把暂存区里的内容保存成一个本地版本快照，生成一条 commit 提交记录，保存在本地Git仓库，产生唯一提交id。

3. 本次实验中 `git restore notes.md` 的作用是:
撤销工作区中还没有 add 到暂存区的修改，把 notes.md 恢复成暂存区/最近一次提交的状态，丢弃工作区临时新增的文字。

4. `commit` 与 `push` 的区别是:
`commit` 只在本地仓库生成版本快照，改动仅存在自己电脑；
`push` 将本地已经 commit 完成的提交上传推送到远程仓库，让远程服务器同步本地版本。
